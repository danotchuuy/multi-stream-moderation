Privacy Policy

Last updated: September 5, 2026

Multi-Stream Moderation ("the application") is a chat-moderation tool that lets a streamer or moderator connect their Twitch, Kick, and/or YouTube accounts to view and moderate live chat from one place. This policy explains what data the application accesses when you connect an account, how that data is used and stored, and how you can revoke access at any time.

This application is self-hosted: it runs on infrastructure that the person or organization operating it controls, rather than a service run centrally by its developer. If you're using an instance someone else set up for you, they are the operator of that instance and this policy describes how the application itself behaves; direct data-specific questions to them, or to the contact below if you're unsure who that is.

Information the application accesses

When you connect an account, the application requests:

  • YouTube / Google: your channel ID, channel name, and profile image (to identify you and show your connected account), an OAuth access token and refresh token scoped to https://www.googleapis.com/auth/youtube.force-ssl, the live chat messages of a broadcast you choose to open, and the ability to post messages, delete messages, and time out or ban chatters in that live chat on your behalf.
  • Twitch: your Twitch user ID, login, display name, and profile image, an OAuth access token and refresh token, the chat messages of channels you moderate or choose to view, and the ability to send messages and take moderation actions on your behalf.
  • Kick: your Kick user ID, username, and profile image, an OAuth access token and refresh token, the chat messages of channels you moderate or choose to view, and the ability to send messages and take moderation actions on your behalf.

The application only requests the access it needs to display chat and carry out the moderation actions (delete, timeout, ban, send message) it offers — it does not read email, uploads, subscriber lists, watch history, or anything else outside live chat.

How this information is used

  • To show you which account(s) you're connected as.
  • To display live chat from the channel or broadcast you pick.
  • To carry out moderation actions you explicitly trigger (delete a message, time out or ban a chatter) and to send messages you compose, all performed as you, using your own access token.
  • To keep you signed in between visits, and to refresh an expired access token automatically using the stored refresh token.

Chat messages are relayed to your browser in real time to display them and are not written to any database or log — the application keeps no history of chat content once a session ends.

Google user data and the Limited Use policy

Multi-Stream Moderation's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Concretely: data obtained through the YouTube Data API is used only to provide and improve the live-chat viewing and moderation features described above. It is never sold, never used for advertising or ad targeting (by the application or anyone else), and never shared with third parties except where necessary to operate the feature itself (i.e. calls to YouTube's own API) or where required by law.

Where data is stored

  • Your browser only ever holds an opaque, random session token in an HttpOnly cookie — it never receives your actual Google/Twitch/Kick access or refresh tokens directly.
  • On the server, your profile info and OAuth tokens are held in memory, and — if the operator has configured persistent sessions — encrypted at rest (AES-256) in a local file so you don't have to reauthorize every time the server restarts.
  • Chat message content is never persisted to disk or to any database; it exists only transiently while being relayed from the platform to your open browser tab.

Revoking access and deleting your data

You can disconnect at any time, in any of these ways:

  • Use the "disconnect" / logout option in the application itself, which deletes your stored session and tokens from the server immediately.
  • Revoke the application's access directly from your account's own permissions page: Google Account permissions for YouTube, Twitch connections settings , or Kick security settings. This immediately invalidates the tokens the application was holding, even if you can't reach the application itself.

Children's privacy

This application is a tool for streamers and moderators and is not directed at children. It does not knowingly collect information from anyone under the age required by each connected platform's own terms of service.

Changes to this policy

If how the application handles data changes materially, this page will be updated and the "Last updated" date above will change accordingly.
